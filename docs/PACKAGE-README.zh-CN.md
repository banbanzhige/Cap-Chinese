# Cap Chinese 0.5.9（Windows x64）

这是基于官方 Cap 0.5.9 的社区中文构建，不是官方发行版，不是覆盖官方程序的补丁。

本次为 R2 修正版：修复启动“未找到文件”和登录后显示“F:\ 的索引”的打包路径问题，同时修复设置窗口背景初始化时的脚本异常。请使用 `0.5.9-zh-CN` 目录，不要再打开旧命名的目录。

## 使用

1. 将整个压缩包解压到有写入权限的普通文件夹。
2. 双击 `Cap Chinese.exe`。不要只提取 EXE，也不要覆盖官方安装目录。
3. 保留同目录全部 DLL、`cap-cli.exe`、`cap-exporter.exe`、`cap-muxer.exe` 和 `assets`。

需要 Windows x64、可用的图形驱动及 Microsoft Edge WebView2 Runtime。本机已安装 WebView2；其他电脑如缺少，请从微软官网下载并安装：<https://developer.microsoft.com/microsoft-edge/webview2/>。本包包含 MSVC 运行库 DLL，无需安装 Node、Rust 或开发工具。

如果系统提示未知发布者，请先核对来源和 SHA-256。本包未签名；不要关闭杀毒软件、SmartScreen 或修改系统执行策略。本包不会自动安装软件、注册文件关联或修改 PATH。

## 汉化范围

主界面、设备与目标选择、首次引导、录制状态、视频编辑器、时间轴、字幕、导出、截图编辑器、设置子页、提示与错误弹窗、窗口标题、托盘菜单和系统通知已进行中文适配。参考 PingGai/Cap-Chinese 的旧版译法，并按 0.5.9 新增界面重译。

保留品牌名、快捷键、编码/格式名、命令及参数、设备名、用户文件与文字。服务器返回的错误、在线网页、更新日志内容、底层技术错误和 CLI 命令行帮助仍可能为英文。因此不宣称每一种运行状态都已 100% 中文。

## 与官方版并存

- 中文版配置/工程默认目录：`%APPDATA%\so.cap.desktop.zh`；日志：`%LOCALAPPDATA%\so.cap.desktop.zh\logs`。
- 辅助程序默认只查找中文版的账号、录屏目录及自动化规则；不导入官方版账号。
- 采用独立的 `cap-zh` 协议名。在线登录回调、云端服务兼容性尚未实际验收，可能需要后续适配；没有绕过授权或收费限制。
- 不要同时运行两个版本，以免它们竞争全局快捷键、摄像头等系统资源。
- 设置中的“安装命令行工具”是上游的可选 PATH 安装功能；本包未执行它。如已有官方 `cap` 命令，请不要点击安装/卸载，以免影响现有命令入口。
- 解压运行不等于所有数据随程序移动：账号、设置与新工程仍保存到上面列出的系统用户目录。移除程序文件夹不会删除这些数据。

## 构建与验证边界

本包使用 Debug 构建（关闭常规控制台窗口），不提供官方自动更新或安装器。文件较大，性能和日志量不同于正式 Release。

已做前端语法/文案保护检查、Biome 检查、前端构建、Rust 编译检查、主程序链接及打包依赖检查。未进行中文界面真机逐页验收，未运行录制或导出测试，不使用 computer-use。遇到布局或漏译问题，可提供截图和具体操作位置。

启动修复验收：通过 Playwright 连接实际 EXE 内的 WebView2，确认已登录状态的中文主界面、录制模式说明、通用设置和快捷键页面加载及切换正常。测试不等于录制/导出全功能验收。页面路径与初始化时序有新增自动回归检查。
